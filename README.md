## About

**ColloTalk** is a modern chat application focused on simplicity, speed, and comfortable conversations.

The name is inspired by the Latin word *colloquium*, meaning conversation or dialogue, combined with the English word *talk*.

ColloTalk is currently in its initial development stage.

## Project Goals

ColloTalk aims to provide:

- A clean and distraction-free chat experience
- Fast and responsive message delivery
- Comfortable use on desktop, tablet, and mobile devices
- A simple interface that is easy to understand
- A foundation that can grow into a full online messaging platform

## Planned Features

### Initial Release

- User name setup
- Message composition and display
- Send messages with Enter
- Local message history
- Responsive layout
- Dark interface
- Desktop support
- Tablet support
- Mobile support

### Future Releases

- Online accounts
- Real-time messaging
- Direct messages
- Group conversations
- User profiles
- Profile pictures
- Online status
- Message editing and deletion
- Read receipts
- Typing indicators
- Reactions
- Image and file sharing
- Notifications
- Search
- Light and dark themes

## Technology

The initial version of ColloTalk is planned to use:

- HTML
- CSS
- JavaScript
- Vite
- LocalStorage

Additional online services may be selected later when real-time messaging and account systems are introduced.
